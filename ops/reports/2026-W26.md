**Top provisional failure labels (all labels provisional pending gold-set calibration):**

1. **Reasoning Drift** — 7 episodes: agent reasoning diverges from task goal mid-trajectory without a visible environmental trigger.
2. **Goal Hallucination** — 5 episodes: agent pursues a sub-goal or task variant not present in the actual instruction.
3. **Location Hallucination** — 2 episodes: agent references or navigates to UI elements or file paths that do not exist in the observed state.
4. **Action Looping (Repetition)** — 1 episode: agent replays the same action sequence without progress.
5. **Hidden Operation Blindness** — 1 episode: agent fails to account for a background or system-level operation affecting task state.

**So what:** Reasoning Drift and Goal Hallucination dominating the early sample suggests the A3B model's chain-of-thought is the primary failure surface — but with only 4 % of episodes labeled, these proportions should be treated as directional hypotheses until the human review queue is resolved and the labeled set scales to at least ~50–100 episodes.
